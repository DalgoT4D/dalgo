# November 23, 2026

Maps now know where to look. If your data covers just one state, the map can open straight on its districts, so you skip the click.

## Smarter Maps

- **Auto Zoom** — turn it on in a map's customisation settings, and when your data covers only one region, the map opens zoomed into it. For example, one state opens on its districts. It's available once your map has drill-down levels set up.
- **Real zeros on the map** — a region whose value is genuinely 0 now shows as 0 instead of looking like it has no data. Regions with no data at all are still marked as "no data", so you can tell the two apart.
## Fixes

- **Downloaded maps** — downloaded maps now show the filtered numbers, matching what you see on screen.
- **Long column names in filters** — hover over a column in the filter dropdown to see its full name.
- **Dataset list when a connection service is down** — the list of datasets in the chart builder used to disappear when one of Dalgo's background services was having a bad day. It now loads straight from your warehouse.
