# October 15, 2026

## 🛠 Admin Portal

We've shipped the **Dalgo Admin Portal** (`/admin`) — a platform operations hub for managing organizations, users, feature flags, and broadcast notifications, accessible only to platform admins.

### Organization management

- Create orgs with plan, billing frequency, Superset config, and start/end dates for trial accounts
- Edit all org fields from the portal (was read-only before)
- Delete an org with a pre-flight impact check that shows exactly how many users, warehouses, connections, pipelines, dashboards, and charts will be destroyed — the confirm button stays locked until those numbers have loaded
- Org detail page with Overview, Users, and Feature flags tabs

### User management

- Invite users to an org, change their role, and remove them — all from the admin portal, bypassing the per-org role caps that apply to in-org admins
- Removal shows the same pre-flight impact warning

### Broadcast notifications

- Compose and send a broadcast to the whole platform, a single org, or a selection of orgs
- Narrow by Superset clients only
- Choose in-app, email, or both
- Live recipient count preview before you send
- Full send history with pagination
- Draft is preserved if you tab away or if a send fails

### Feature flags

- Toggle platform features (Reports, Data Quality, etc.) on or off per org

### Security model

- Every admin route is gated on `UserAttributes.is_platform_admin` — Django superusers without that flag are rejected
- Multi-tenancy verified: deleting an org cleans up only that org's data; users in multiple orgs keep their accounts and other memberships
