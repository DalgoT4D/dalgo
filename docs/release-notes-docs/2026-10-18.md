# October 18, 2026

Dashboard filters stopped at the first 100 values. Now they don't. Also, Dalgo Copilot and BigQuery have finally learned to get along.

## Search Any Value in Dashboard Filters

Dropdown filters used to load only the 100 most common values, so the rest were out of reach. Not anymore.

- **Search goes all the way down** — type in a filter's dropdown and Dalgo searches your full data in the warehouse, not just the values already loaded. Any district, school, or beneficiary name can now be found and picked.
- **Case doesn't matter** — "pune", "Pune", and "PUNE" all find the same thing.
- **Works on shared dashboards too** — people viewing a public dashboard or shared report get the same search.

## Fixes

- **Copilot questions on BigQuery** — Copilot sometimes wrote queries BigQuery couldn't read, so your question got blocked. Copilot now writes them the way BigQuery expects, including for columns with names like "select" or "order".
- **Copilot seeing all your BigQuery datasets** — Copilot used to look for your datasets in a default region, so it could miss some of them. It now looks in the region you picked when you set up your warehouse, so it sees all your datasets.
- **Copilot and sensitive columns on BigQuery** — questions touching columns marked as personal data (PII) failed with an error on BigQuery warehouses. They now work, with that data still protected.
- **Setting up or editing a BigQuery warehouse** — saving a BigQuery warehouse could fail after a recent Airbyte update. Creating and editing it works again.
