# Files

- [Workflow: add a backend endpoint and a webapp feature](add-endpoint-and-webapp-feature.md) - Layer-by-layer checklist for shipping a new API endpoint in the Django Ninja backend and the webapp feature that calls it, using the KPI feature as the worked example. Covers model and migration, schema, service, router, seed permissions, route mounting, SWR hook, component, analytics, data-testid and tests, and what breaks when a step is skipped.
- [Workflow: deploy to staging and production](deploy-staging-production.md) - How the Deploy to Staging and Deploy to Production GitHub workflows build arm64 images to GHCR, SSH to a docker-compose host, roll back or apply Django migrations, and what is (and is not) verified or rolled back automatically. Also covers the separately built Prefect job-runner image.
- [Workflow: write and apply a Django migration](django-migrations.md) - How to create, review, test and apply Django migrations in backend/ddpui/migrations, why oldmigrations is inert, when seed fixtures must be re-loaded, and how deploy-time migrate and staging rollback constrain what a migration may do.
- [Workflow: an NGO's pipeline end to end](ngo-pipeline-end-to-end.md) - Traces one org's data path from connecting a warehouse, through Airbyte source, connection and sync, dbt transforms and a scheduled pipeline run, to charts and dashboards. It names the component that owns each hop (webapp, Django backend, Airbyte, prefect-proxy, Prefect, warehouse) and where each hop fails.
